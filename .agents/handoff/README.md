# 交接文档模板

每次会话结束、切换负责人或遇到阻塞时，在本目录下创建
`<yyyy-MM-dd>-<任务 slug>.md`。**交接文档只保留在本地，不提交到 git。**

```markdown
# <任务名称>

## 目标与背景
- 要解决什么问题，为什么现在做。

## 当前状态
- 已完成：
- 进行中：
- 未开始：

## 改动文件与关键设计决策
- `path/to/file`：改了什么，为什么这样设计。

## 待办事项
- [ ] 具体到文件与函数。

## 验证命令与最近结果
- `npm run build`：通过 / 失败原因。
- `cargo test --manifest-path src-tauri/Cargo.toml`：通过 / 失败原因。

## 风险与坑点
- 容易踩坑的地方、已知限制、需要人工确认的事项。
```
